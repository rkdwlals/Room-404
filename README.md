# room: 404

로블록스로 만든 **1인칭 좀비 FPS**입니다.

- 3인 개발, 서브 개발자·사운드 디자이너
- 플레이 영상: [포트폴리오에서 보기](https://rkdwlals.github.io/#room404)
- Roblox Studio · Luau · Cubase

## 맡은 역할

### 개발
- 총기 시스템
- 좀비 NPC 시스템
- 맵 일부 디자인 (벽에 걸린 그림, 가운데 시체, 힐팩 배치 등)

### 사운드
- 킬 수를 세서 1킬부터 5킬 이상까지 다섯 단계로 다른 킬 사운드가 나오는 스크립트
- 구급상자 회복음과 재장전음 직접 제작
- Cubase로 BGM 3곡을 작곡하고, 곡을 차례로 트는 재생 목록 스크립트 작성

소리 출처: 회복음, 재장전음, BGM 3곡은 직접 제작. 킬 사운드와 총소리 등은 외부 소스를 사용했고, BGM 중 1곡은 기존 곡입니다.
